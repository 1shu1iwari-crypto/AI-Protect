# 48-hour finale execution plan

Assumes a team of 2-4 students. With two people, combine app + UX and engine + validation roles. Preserve this runnable baseline before optional research work.

| Hours | App / UX | Engine / evaluation | Backend / safety | Exit evidence |
|---|---|---|---|---|
| 0-4 | Verify target Android/browser devices; consent screens | Freeze synthetic suite and thresholds | Audit data contract and seed candidate review | Baseline demo and checks reproduce |
| 4-12 | Native share-text and QR adapter if build tooling permits | Add independently authored paraphrases/negations | Authenticated reporter sandbox; quotas | Two workflows run end-to-end locally |
| 12-20 | Optional controlled VoIP activation only | Evaluate small ASR pack; typed-transcript fallback | Retention/deletion and poisoning checks | Raw audio never enters campaign API |
| 20-30 | Payment-adapter simulator and warning timing | Compare rules-only vs hybrid; family holdout | Candidate clustering + analyst review | Pre-authorization warning trace |
| 30-38 | Midrange-device cold start, accessibility and offline QA | PR curves only on enough independently labelled data | Auth/replay/abuse tests; no auto-block | Report limitations and failed cases |
| 38-44 | Consented usability tests, plain-language alerts | Measure warning burden and stage-to-warning | Verify logs/cache contain no private content | Reproducible results and privacy proof |
| 44-48 | Rehearse refund + investment + benign QR demo | Freeze versions, disclose AI and assets | Backup runnable build and PDF | 3-minute offline-capable demo |

Priority order: reliable local workflow and payment pause; human-reviewed candidate reporting; mobile adapter; controlled audio only if lawful access and tooling are ready. HDBSCAN/ADWIN and financial graph models are stretch research, not required for a reliable finale demo.

Acceptance targets (future targets, not measured claims): payment-context warning under 300ms P95 on a midrange device; no raw content in network requests/logs/cache; legitimate interruption burden below 2 per 100 independently labelled flows; >90% pre-payment intervention on a representative consented study. Stop claiming these targets if evidence does not support them.
